Problem Statement Academic Challenges

3 Core Challenges Faced by Students

Traditional static to-do lists fail students due to lack of intelligent scheduling and focus assistance.

📚

1. Task Overload & Chaos

Students juggle multiple subjects, lab records, assignments, and exams without a clear understanding of urgency vs. importance.

⏳

2. Ineffective Time Slots

Static to-do lists don't allocate specific timetable slots, leading to chronic procrastination and last-minute cramming.

🧠

3. Distraction & Burnout

Unstructured study hours without timed intervals lead to mental fatigue, phone distractions, and incomplete homework.

Key Solutions Intelligent Task Engineering

How SmartTask Planner Solves These Problems

A smart, full-stack student planner integrating automated scheduling and focus tools.

🎯

Smart Priority Scoring

Algorithm computes urgency weights based on deadline proximity, difficulty, and estimated hours to order tasks automatically.

📅

Auto Daily Slotting

Reads student study preference hours and auto-slots unfinished tasks into an optimal, conflict-free timetable.

⏱️

Pomodoro Focus Mode

Built-in 25/5 min focus timer with distraction blockers and session logging for continuous productivity tracking.

Project Scope Aims & Scope

Objectives of the Project

Primary goals achieved during design and implementation.

Core Technical Deliverables

  • Responsive SPA: Fast React 19 interface with real-time state management.
  • Secure REST API: Express backend protected by JWT Bearer token authentication.
  • NoSQL Storage: Mongoose schemas for flexible user tasks, tags, and preferences.
  • Scheduler Engine: Heuristic algorithm for automated timetable allocation.

Target User Experience

  • Zero Clutter: Minimalist, student-first aesthetic optimized for laptops & phones.
  • Actionable Analytics: Daily hours studied, completion rates, and streak counters.
  • Accountability: Role-based access control (Student vs. Administrator views).
System Specifications Performance & Security

Key System Targets & Specifications

Non-functional requirements and quality benchmarks achieved.

⚡

Speed & Performance

  • Initial Load Time: Under 1.2 seconds via Vite optimized bundling
  • API Response Time: < 80ms for CRUD operations
  • Bundle Size: < 250 KB gzip compressed
  • Availability: 99.9% uptime with stateless architecture
🔒

Security & Storage

  • JWT Authentication: 256-bit cryptographically signed tokens
  • Password Protection: Salted password hashing via bcryptjs
  • CORS & Sanitization: Strict header security & MongoDB injection defense
  • Privacy: Data isolated strictly per user account ID
